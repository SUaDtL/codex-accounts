Historical foundation, discovery, data and crypto evidence remains in validation.md and the corresponding PRs, bound to each tested source commit; it does not transfer to CA-04A.

Three inherited two-user helpers were NOT RUN. The owner merged PR #6 into the former CA-03A branch; PR #7 preserves and carries that storage dependency to main.

CA-04A local Rust 1.90.0 workspace tests passed, including 44 storage cases (22 journal/coordinator and 22 inherited storage). Formatting and Clippy retain blocking checks. Final source/Python/dependency results and hosted native journal tests are recorded in validation.md and on the final PR #7 head after publication.

Journal fault tests restart from independently retained encrypted bytes and controlled external resources, requiring reachable newest generations and complete holds. They include each durable forward/restoration write plus request, cancellation and recovery-choice commits; helper signals and observations never become exit or Desktop-identity proof.

Native tests use synthetic objects and child-test processes only. Physical power loss, directory-metadata ordering, ordinary-user isolation/unavailable stores, real Desktop Q0 and independent macOS remain qualification gaps. All complete requirements and T-01 through T-34 stay open.

No main update, merge, force push, release or live account operation is part of this implementation. CA-04B is a selected future packet, not an automatically executed phase.
