# CA-02: in-place T-07 review amendment

Status: implemented in the review branch with its source-manifest migration;
owner review/merge determines adoption. No installation is qualified and no
credential operation is enabled by this amendment.

## Scope and decision

The original architecture/F-006 permits a positively established, exact-build
file backend, including a qualified official default. Original T-07 said only
explicit file mode proceeds. This change aligns that single acceptance row:

> Explicit file, positively established exact-build official file default, keyring, auto-with-file, auto-with-keyring, encrypted/secrets, ephemeral, inaccessible-store and unresolved-precedence fixtures. Only an otherwise-qualified installation with a positively established effective file backend is eligible. A missing setting alone never establishes that default. Auto, keyring, unsupported sources and unresolved evidence remain ineligible; no backend or keyring state is changed.

Only T-07 changes in the canonical specification and visible reading projection.
The 43 requirements, 34 acceptance IDs, product version 0.1.0 and all other source
content are preserved. Document revision `ca-02-t07-proposal-1` identifies the
review candidate, not an application release or native qualification receipt.

`tools/spec_projection.py` still checks every modeled section and source note.
