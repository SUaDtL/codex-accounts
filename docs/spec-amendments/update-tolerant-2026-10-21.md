# Application updates and compatibility

On 2026-10-21 the owner directed: "definitely do not tie it to exact build, the codex application updates multiple times per day sometimes".

Compatibility is determined by current runtime capabilities, effective file storage, supported credential schema, policy, process lifecycle and recovery behavior. A normal official application update does not require a new manual approval or catalog entry. Executable identities are still checked to detect an update during an operation.

This amendment does not permit unknown credential stores, configuration rewrites, plaintext vaults, forced process termination or unverified identity claims. The final acceptance includes an owner-assisted A -> B -> A trial. The owner has agreed to sign in personally when the app is ready.

The original specification and earlier T-07 amendment remain reproducible through the existing provenance tool. This is the owner's explicit change in product requirements, not evidence that runtime integration is already complete.
