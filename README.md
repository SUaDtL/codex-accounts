# Codex Accounts

A locally controlled, manual account-handoff tool for the official Codex Desktop application.

This repository is being bootstrapped from the project specification. Development work is proposed through pull requests; no application release or Desktop compatibility qualification is implied by this initial commit.

The product must preserve the newest outgoing credentials, protect inactive credentials, recover from interrupted switches, and distinguish credential installation from confirmation inside Desktop. It must not proxy inference, rotate accounts automatically, modify workspace history, or bypass authentication policy.

No Desktop build is prequalified. Credential-changing functionality must remain unavailable until the required compatibility and recovery evidence is established.
